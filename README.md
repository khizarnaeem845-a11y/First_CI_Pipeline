# First_CI_Pipeline

DevOps Assignment 4: Python programs 21–30 with pytest test cases.

- `codes/`: program source files.
- `test_cases/`: matching pytest test files.

The assignment's setup files (`requirements.txt`, `pytest.ini`, `.gitignore`) and GitHub Actions workflow will be added in the next stage, as requested.

When pytest is installed and `pytest.ini` is configured, run the tests with:

```powershell
pytest -v
```
